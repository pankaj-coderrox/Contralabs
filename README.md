# Contralabs Visual Rebuild

Faithful frontend rebuild from the supplied `contralabs.com_.png` screenshot.

## What This Includes

- Next.js App Router with TypeScript
- Tailwind CSS setup
- Installed dependencies preserved
- One responsive visual section per reference slice
- Clean, rebuild-friendly structure

## Commands

```bash
npm run setup
npm run dev
npm run lint
npm run build
```

Open [http://localhost:3000](http://localhost:3000).

## Visual References

Readable section references were generated in `design-references/`.
The rendered section assets live in `public/sections/`.
